💶 Economía

La aportación al bote la realizan todos los cofrades. La diferencia del restaurante se reparte entre quienes asisten.

Puedes repartir el adelanto entre varias personas. La suma debe coincidir con el precio total del restaurante.

Gastos adicionales

🌐 Información pública

Se calcula con los adelantos registrados. El bote financia parte de ese total, no se suma otra vez.

📸 Fotos

Puedes seleccionar varias fotos. La primera será portada automáticamente si todavía no existe.

⭐ Valoración

Solo podrán votar los cofrades marcados como asistentes.

La configuración de valoración se guardará con la comida.

🔒 Cerrar liquidación

¿Quieres cerrar la liquidación de esta comida? Se guardarán las deudas y los reembolsos del bote como pendientes de pago.

Podrás confirmar los cobros y reembolsos desde Administración.

🔓 Reabrir liquidación

¿Quieres reabrir esta liquidación para modificarla?

Solo es posible si todavía no se ha confirmado ningún pago. Las deudas y los reembolsos pendientes se recalcularán cuando vuelvas a cerrarla.
